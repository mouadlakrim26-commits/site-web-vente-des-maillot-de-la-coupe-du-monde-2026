# ⚽ MUNDIAL KITS — World Cup Collection 2026

**MUNDIAL KITS** est un site web e-commerce dédié à la vente de maillots de football des équipes nationales participant à la Coupe du Monde 2026.

Le projet propose une interface moderne, élégante et responsive permettant aux passionnés de football de découvrir les maillots de différentes sélections nationales.

## 🚀 Fonctionnalités

- 🌍 Catalogue de maillots de différentes équipes nationales.
- 🔎 Recherche par pays et par joueur.
- 🏆 Filtrage des équipes par continent et confédération.
- 👕 Présentation des maillots avec images et prix.
- ⚽ Sélection du joueur, du numéro et de la taille.
- 🛒 Panier d'achat interactif.
- 💱 Sélection de la devise.
- 📱 Interface moderne et responsive.

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- Tailwind CSS
- JavaScript

## 💻 Installation

1. Clonez le dépôt :

```bash
git clone https://github.com/VOTRE-NOM/site-web-vente-des-maillot-de-la-coupe-du-monde-2026.git
```

2. Ouvrez le dossier du projet.
3. Lancez `index.html` dans votre navigateur.

## 🎯 Objectif du projet

Créer une expérience de boutique en ligne moderne et intuitive autour de l'univers du football et de la Coupe du Monde 2026.
